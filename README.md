### Deskripsi Singkat
Proyek Ujian Akhir Semester (UAS) ini berfokus pada pengembangan dan analisis penerapan Deep Learning, khususnya Large Language Model (LLM), dalam menyelesaikan permasalahan nyata pada analisis konten digital YouTube. Proyek yang dikembangkan berupa sistem YouTube Analyzer berbasis web yang mampu melakukan ringkasan konten (summarization), analisis sentimen, dan evaluasi performa video secara otomatis.

### Langkah Menjalankan Proyek YouTube Analyzer:
1.	Pada terminal setiap folder Back-end dan Front-end jalankan perintah "npm install"
2.	Pada terminal folder Back-end jalankan perintah "npm run dev"
3.	Pada terminal folder Front-end jalankan perintah "npx react-scripts start", lalu otomatis akan terbuka pada local host perangkat kita.
4.	Input link youtube yang dicopy dari search bar, lalu paste pada text boxnya (Note: Jika ingin menginput lebih dari 1 link klik enter terlebih dahulu sebagai pemisah link 1 dengan lainnya)
5.	Klik button "Mulai Analisis"
6.	Setelah selesai maka akan muncul output yang menampilkan judul, URL youtube, ringkasan singkat, sentimen(positive, neutral, negative), jumlah likes, views, dan comments.
